# HTML로 엮기

`<book>/md/`를 웹에서 읽는 책으로 엮을 때 따르는 지침입니다. 이 지침을 받은 AI가 HTML을 만듭니다.

**엮는 사람의 취향이 먼저입니다.** 사용자가 분위기, 색, 글꼴, 구성, 참고할 사이트를 말하면 그것을 따릅니다. 말하지 않은 부분에만 아래의 기본을 씁니다. 기본은 "종이책을 펼친 듯한 조용한 서재"입니다. 오래 읽어도 피곤하지 않고, 본문과 원문이 한눈에 구분되는 것이 목표입니다.

## 시작하기 전에 (한 번만 묻기)

- 원하는 분위기나 참고할 사이트·책이 있는지. 없으면 기본 스타일로 합니다.
- 결과를 둘 곳. 기본은 `<book>/html/`입니다.
- 인터넷 없이도 열려야 하는지. 그렇다면 외부 스크립트를 쓰지 않는 방식(아래 "만드는 방법"의 1)으로 합니다.

## 지킬 것

- **글을 바꾸지 않습니다.** md의 문장, 표, 링크 대상, 부록 원문을 그대로 옮깁니다. 요약하거나 다시 쓰거나 빼지 않습니다.
- **모든 쪽을 싣습니다.** 차례는 `SUMMARY.md`의 순서와 들여쓰기(묶음 안의 묶음)를 그대로 따릅니다. `## ` 머리글이 차례의 묶음 이름입니다.
- **링크가 모두 통해야 합니다.** md 사이의 상대 링크(`../../appendix/atoms/x.md#앵커`)를 HTML 안의 같은 쪽·같은 자리로 바꿉니다. `http(s)` 링크는 새 탭으로 엽니다.
- `<a id>` 앵커, `<details>`, 표, 코드 블록, 이미지(`assets/`)를 살립니다.
- `<book>/md/`, `<book>/manuscript/`, 원본 저장소는 고치지 않습니다. 변환에 쓰는 스크립트는 `<book>/.work/`에 둡니다.
- 패키지를 설치하지 않습니다(`npm install` 등). 사용자가 허락하지 않았다면 외부 스크립트는 버전을 고정한 CDN 주소 하나(마크다운 변환기)까지만 씁니다. 글꼴은 시스템 글꼴을 쓰고, 웹 글꼴은 사용자가 원할 때만 씁니다. 분석·추적 스크립트는 넣지 않습니다.

## 화면 구성

| 자리 | 내용 |
| :--- | :--- |
| 왼쪽 차례 | 맨 위에 책 이름, 그 아래 검색 상자(선택). 차례는 "목차 → 여는 글 → 부 제목(작은 머리글) 아래 장 → 부록 · 원문 찾아보기 → 다른 순서로 보기" 순서입니다 |
| 부록 차례 | "원문을 읽는 법" 아래 관련 문서, 그리고 `L0 · …`부터 `L4 · …`까지 Layer 묶음. Layer 아래의 결정 목록은 "관련 문서 N편"처럼 접어 두고, 지금 읽는 쪽이 든 묶음만 펼칩니다 |
| 가운데 본문 | 쪽 제목(h1)과 본문. 부록 원문 쪽이면 맨 위의 "← 본문으로 돌아가기" 줄을 작은 링크로 둡니다 |
| 본문 아래 | "← 이전 / 다음 →" 쪽 넘김. 왼쪽에 이전 쪽, 오른쪽에 다음 쪽 제목을 작은 머리말("이전", "다음")과 함께 둡니다. md 끝의 `← 이전 · 목차 · 다음 →` 줄은 이것으로 대신하고 두 번 보이지 않게 합니다 |
| 좁은 화면 | 768px 아래에서는 차례를 위쪽 메뉴 단추로 접고, 본문을 화면 폭에 맞춥니다 |

- 지금 읽는 쪽은 차례에서 강조합니다(옅은 바탕과 왼쪽 굵은 선).
- 쪽을 옮기면 본문 맨 위로, 앵커가 있으면 그 절로 갑니다. 브라우저의 뒤로 가기가 통해야 합니다.
- 장 쪽에서 문단 끝의 근거 링크는 본문 흐름을 끊지 않게 보통 링크와 같게 둡니다. ` · `로 이어진 모양도 그대로 둡니다.
- 여는 글(표지)의 "읽는 순서" 표는 장 링크와 장면이 한 줄에 보이게 하고, "첫 장 읽기 →"는 강조된 링크로 둡니다.

## 기본 스타일

색은 토큰으로 정하고, 어두운 모드에서 토큰만 바꿉니다.

| 토큰 | 밝게 | 어둡게 | 쓰는 곳 |
| :--- | :--- | :--- | :--- |
| `--paper` | `#faf8f3` | `#1c1a17` | 본문 바탕 |
| `--sidebar` | `#f1eee5` | `#23201c` | 차례 바탕 |
| `--ink` | `#292921` | `#ebe6dc` | 글자 |
| `--muted` | `#6d685c` | `#a7a093` | 보조 글자: 상태·날짜, 차례의 묶음 머리글, summary |
| `--rule` | `#d9d4c7` | `#3b3731` | 구분선, 표 테두리, 인용 선 |
| `--accent` | `#794638` | `#d9a08a` | 링크, 현재 쪽 표시, 단추 |
| `--accent-soft` | `#efe4dd` | `#3a2b25` | 현재 쪽 바탕, 표 머리 행 |
| `--code-bg` | `#f2efe8` | `#26231f` | 코드 바탕 |

```css
  --paper: #faf8f3; --sidebar: #f1eee5; --ink: #292921; --muted: #6d685c;
  --rule: #d9d4c7; --accent: #794638; --accent-soft: #efe4dd; --code-bg: #f2efe8;
  --sans: -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif;
  --serif: "Noto Serif KR", AppleMyungjo, "Apple Myungjo", Batang, Georgia, serif;
  --mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --paper: #1c1a17; --sidebar: #23201c; --ink: #ebe6dc; --muted: #a7a093;
    --rule: #3b3731; --accent: #d9a08a; --accent-soft: #3a2b25; --code-bg: #26231f; }
}
:root[data-theme="dark"] { /* 위와 같은 어두운 값 */ }
```

| 요소 | 기본 |
| :--- | :--- |
| 본문 글자 | `--sans`, 17px 안팎, 줄 간격 1.9, 문단 사이 1em. 한 줄은 한글 38~42자(약 40em)를 넘지 않게 |
| 쪽 제목 (h1) | `--serif`, 2.6~2.8rem, 굵게, 아래에 `--rule` 가는 선과 넉넉한 여백 |
| 절 제목 (h2) | `--serif`, 1.4~1.5rem, 위 여백 2.2em 안팎 |
| 작은 제목 (h3) | `--sans`, 1.05rem, 굵게 |
| 굵은 글 | 화면 이름·버튼 같은 UI 말. 색은 바꾸지 않습니다 |
| 링크 | `--accent`, 얇은 밑줄을 글자에서 조금 띄웁니다(`text-underline-offset: 3px`). 지나가면 밑줄을 진하게 |
| 표 | 머리 행 `--accent-soft`, 가는 가로줄만. 칸 안쪽 여백 0.6em 1em. 넓은 표는 표 안에서만 가로로 넘깁니다 |
| `<details>` | 접힌 상태가 기본. summary는 `--muted` 작은 글자와 ▸ 표시, 펼치면 ▾ |
| 인용 (`>`) | 왼쪽 3px `--rule` 선, `--muted` 글자. 원문 쪽의 상태 줄과 "아직 편집하지 않은 장" 알림이 여기에 해당합니다 |
| 코드 | `--mono`, `--code-bg`, 둥근 모서리 6px, 코드 블록은 가로로 넘깁니다 |
| 구분선 (`---`) | `--rule` 1px, 위아래 여백 넉넉히 |
| 차례 | `--sidebar` 바탕, 너비 280~300px, 글자 0.92rem. 부 제목은 `--muted` 작은 굵은 글자 |

- 부록 원문 쪽은 본문 쪽과 같은 틀을 쓰되, 원문 영역(`<!-- original:begin -->`과 `<!-- original:end -->` 사이)을 아주 옅은 바탕이나 왼쪽 선으로 구분해 "편집한 글이 아니라 원문"임을 알 수 있게 합니다.
- 밝게·어둡게를 고르는 단추가 있으면 좋습니다(`data-theme`). 고른 값은 브라우저에만 기억합니다.
- 인쇄할 때는 차례·검색·쪽 넘김을 숨기고 본문만 남깁니다. `<details>`는 펼친 채로 인쇄합니다.
- 접근성: "본문으로 건너뛰기" 링크, 차례는 `<nav aria-label="목차">`, 글자와 바탕의 대비 4.5:1 이상, 키보드로 차례·접기·쪽 넘김을 조작할 수 있게 합니다.

## 만드는 방법

둘 중 하나를 고릅니다. 사용자가 정하지 않았으면 1을 씁니다.

1. **쪽마다 HTML**: 의존성 없는 Node 스크립트(`<book>/.work/html.mjs`)로 md 쪽마다 `.html`을 만들고, 공통 `book.css`와 차례를 넣습니다. 링크의 `.md`를 `.html`로 바꿉니다. 인터넷 없이 열리고, 어떤 정적 호스팅에도 올릴 수 있습니다. 이 책의 md는 제목, 문단, 목록, 번호 목록, 표, 인용, 코드(울타리·인라인), 굵게, 링크, 이미지, `<details>`, `<a id>`만 씁니다. 그만큼만 변환하면 됩니다.
2. **한 파일 읽기 화면**: `index.html` 하나에 모든 md를 넣고, 주소의 `#` 뒤에 md 경로를 두어(`#chapters%2Fplayer%2Fstart.md`) 쪽을 바꿉니다. 마크다운 변환기는 버전을 고정한 CDN에서 불러옵니다. 파일 하나로 주고받기 쉽습니다.

어느 쪽이든 HTML 주석(`<!-- … -->`)은 화면에 보이지 않아야 합니다. md에 든 HTML은 `<details>`, `<summary>`, `<a>`, `<img>`, `<br>`만 태그로 살리고, 나머지(특히 `<script>`, `<style>`, `<iframe>`, `on…` 속성)는 실행되지 않게 글자로 보여 줍니다. 부록 원문에는 그런 글자가 들어 있을 수 있고, 그것은 원문의 글자일 뿐입니다.

## 확인

- 차례의 모든 항목이 열리고, 본문과 부록의 모든 링크가 같은 책 안의 쪽·자리로 갑니다. 깨진 링크가 없습니다.
- 앵커 링크(`#concept_…`)가 그 절로 갑니다.
- 375px 폭에서 본문이 가로로 넘치지 않습니다(표와 코드 블록 안쪽은 넘겨도 됩니다).
- 밝게·어둡게 모두에서 글자, 링크, 표 머리, 현재 쪽 표시가 잘 보입니다.
- 원문 쪽 몇 개를 골라 md와 견주어 글이 같은지 봅니다.
- 보고: 결과 경로(처음 열 파일), 고른 방식(1·2), 사용자의 취향을 반영한 곳과 기본을 쓴 곳.
